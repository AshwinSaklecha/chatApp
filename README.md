# 💬 Modern Chat Application

A sleek, responsive real-time chat application built with HTML, CSS, and JavaScript. Features a beautiful video background, smooth animations, and persistent message storage.


## ✨ Features

- 🎥 **Dynamic Video Background**
  - Elegant background video with perfect opacity
  - Seamless visual experience

- 👤 **User Management**
  - Simple username-based authentication
  - Personalized chat experience
  - User session management

- 💬 **Real-time Messaging**
  - Instant message delivery
  - Distinctive message styling for sender and receiver
  - Timestamp support
  - Auto-scroll to latest messages

- 💾 **Data Persistence**
  - Local storage integration
  - Chat history preservation
  - Session management

- 🎨 **Modern UI/UX**
  - Responsive design for all devices
  - Smooth animations and transitions
  - Gradient message bubbles
  - Clean and intuitive interface

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Storage**: LocalStorage API
- **Design**: Flexbox, CSS Grid, Custom Animations
- **Media**: Video Integration

## 📱 Responsive Design

- Mobile-first approach
- Adaptive layouts
- Flexible chat container
- Dynamic scaling for different screen sizes

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/AshwinSaklecha/chat-application.git
   ```

2. Navigate to the project directory:
   ```bash
   cd chat-application
   ```

3. Open `index.html` in a modern web browser

## 💻 Usage

1. **Join Chat**:
   - Enter your username
   - Click "Join Chat" button

2. **Send Messages**:
   - Type your message in the input field
   - Press Enter or click Send button
   - Messages appear with different styles for sender/receiver

3. **Leave Chat**:
   - Click "Leave" button to exit
   - Chat history is cleared for privacy
